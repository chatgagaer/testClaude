# 达赖喇嘛相关认知调研 —— 网页调查问卷

## 项目简介

本项目是一个静态网页调查问卷，用于配合撰写“关于达赖喇嘛的调研报告”，收集受访者对达赖喇嘛（第十四世达赖喇嘛丹增嘉措）及相关议题的了解程度、信息来源与看法。

问卷以中立、客观为原则设计：题目不预设立场，选项尽量覆盖不同观点，并为每道态度题提供“不了解 / 不愿回答”选项，以减少引导性偏差。

## 调研目的

1. 了解受访者对达赖喇嘛及藏传佛教相关知识的知晓程度；
2. 分析受访者获取相关信息的主要渠道及对渠道可信度的判断；
3. 收集受访者对达赖喇嘛宗教角色、政治角色、转世传承等议题的看法；
4. 比较不同年龄、地区、教育背景、宗教信仰群体之间的认知差异；
5. 为调研报告提供一手数据支持。

## 问卷结构

| 部分 | 内容 | 题量 |
| --- | --- | --- |
| 一、基本信息 | 年龄、性别、地区、学历、宗教信仰 | 5 |
| 二、知晓程度 | 是否听说过、了解程度、对历史事实的认知 | 4 |
| 三、信息来源 | 获取渠道、对渠道可信度的评价 | 3 |
| 四、观点与态度 | 宗教角色、政治角色、转世传承、国际影响等（量表题） | 5 |
| 五、开放性问题 | 自由表达意见与对本调研的建议 | 2 |

题型包括：单选题、多选题、李克特五级量表题、开放填空题。

## 使用方法

1. 直接用浏览器打开 `html/index.html` 即可填写，无需安装任何依赖或启动服务器；
2. 必填题未作答时，提交会提示并定位到对应题目；
3. 提交后页面显示感谢信息，并可将本次答卷**下载为 JSON 文件**，便于汇总分析；
4. 填写过程中会在浏览器本地（localStorage）暂存草稿，刷新页面不会丢失；提交后草稿自动清除。

> 注意：本页面为纯前端实现，不会将数据上传到任何服务器。如需集中收集答卷，可将提交逻辑（`submitSurvey` 函数）对接到自己的后端接口或问卷平台。

## 伦理与隐私说明

- 问卷匿名填写，不收集姓名、联系方式等可识别个人身份的信息；
- 所有问题均可选择“不愿回答”，受访者可随时退出；
- 数据仅用于本调研报告的学术 / 研究用途；
- 报告撰写时应如实呈现各类观点，避免断章取义。
